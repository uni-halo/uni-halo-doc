恋爱日记前台模板 ​

插件内置一套前台（SSR）恋爱日记模板。任何 Halo 主题只要安装并启用本插件，无需写任何代码，即可在站点前台展示恋爱日记页面；有定制能力的主题也可以整页接管或只覆盖页头页脚。

  • 适用插件版本：uni-halo v3.0.0+，Halo：2.26.0+
  • 管理端内容维护见 控制台功能；移动端 App 内管理见项目介绍。

一、包含哪些模板 ​

模板文件页面说明
templates/love.html恋爱日记首页模块入口与内容总览
templates/love-stories.html我们的故事故事列表；列表分页采用 /page/{page} 段式
templates/love-albums.html恋爱相册相册列表；相册详情沿用页内查看器，不单独注册路由
templates/love-daily.html恋爱日记日记流展示
templates/standalone/love.html独立渲染版不依赖主题布局的整页版本
templates/fragments/love-*.html公共片段页面片段、图标 sprite、锁定/解锁表单、浮层等

二、开启与路由 ​

恋爱日记前台能力位于 插件设置 → 恋爱日记主题：

配置项说明
启用开关默认关闭，使用前请先开启
首页路径默认 /love
故事 / 相册 / 日记路径默认分别解析为 /love/stories 等子段。规则：不以 / 开头 = 相对首页路径的子段；以 / 开头 = 绝对路径；留空 = 不注册该页面
主色 / 概览展示等按需调整展示偏好

📷 截图占位

此处待补充：「插件设置 → 恋爱日记主题」配置页截图。

背景图取自「通用配置 → 页面设置 → 恋爱日记页」。

三、主题如何接管 ​

恋爱日记模板的模板名与页面结构在插件兼容版本内保持稳定，主题可以放心依赖：

  1. 整页接管：主题在自己的 templates/ 下放置同名模板（如 love.html）即可整页接管渲染，无需其他配置。
  2. 只覆盖页头页脚：默认模板的页头/页脚由主题提供，主题只需实现自己的页头页脚布局，不必复制整页模板。
  3. 相册解锁表单、图标等均由插件内置提供，主题无需自行实现。

四、相册密码锁定 ​

恋爱相册支持查看密码，锁定行为由插件在服务端保证：

  • 锁定的相册不对外输出照片等内容，页面展示的是页内解锁表单；
  • 访客输入正确密码解锁后，一段时间内无需重复输入；
  • 相关开关（验证码防护、模块解锁）位于 插件设置 → 安全控制，见 插件配置。

五、注意事项 ​

  • 恋爱日记内容（相册、日记、故事、清单）在 Console 恋爱管理中维护，管理员也可直接在移动端 App 内管理；
  • 模板与路由行为升级会在本文档同步说明。
