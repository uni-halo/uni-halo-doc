# 发布小程序

该内容会引导您发布和部署微信小程序。

## 1. 配置服务器域名

在 微信小程序后台，找到菜单 `管理 - 开发管理 - 开发设置 - 服务器域名`，分别在 `request合法域名`、`uploadFile合法域名`、`downloadFile合法域名` 中填写你的 Halo 站点域名（必须是 `https`），点击 `保存并提交` 即可。

## 2. 确认正式环境地址

发布前检查 `env/.env`（或 `env/.env.production`）中的微信正式版地址：

```ini
VITE_SERVER_BASEURL__WEIXIN_RELEASE = 'https://你的域名'
```

同时确认 `VITE_WX_APPID` 为你自己的小程序 AppID。

## 3. 构建生产版本

```bash
pnpm build:mp
```

构建完成后会自动打开微信开发者工具并加载 `dist/build/mp-weixin` 产物。

## 4. 预览

在微信开发者工具中，点击上方的 `预览` 按钮，等待片刻就可以使用微信扫码预览。

## 5. 上传代码

预览没有问题后，在微信开发者工具中点击右上角的 `上传` 按钮，填写 `版本号` 和 `项目备注`，最后点击 `提交` 按钮，等待上传成功提示。

::: tip 命令行上传（可选）
项目内置了 miniprogram-ci 上传脚本，可在 CI 中使用：

```bash
pnpm upload:mp
```

使用前需在微信小程序后台获取上传密钥并配置 IP 白名单。
:::

## 6. 体验版

上传成功后，打开 微信管理后台，找到菜单 `管理 - 版本管理 - 开发版本`，点击 `体验版` 按钮生成体验二维码，扫码即可体验。

## 7. 提交审核

在微信小程序后台 `管理 - 版本管理 - 开发版本` 中，点击 `提交审核`，填写审核信息后提交。

### 7.1 个人资质用户的提交建议

::: warning 为什么有这一节
如 [部署须知](intro.md) 中所述，uni-halo 属于博客/资讯内容类小程序，而**个人主体无法选择资讯类目**，直接提交会被判定为「类目与内容不符」而拒绝审核。以下建议的核心思路是：**让提交的内容看起来符合个人主体可选的类目**（如生活记录、个人分享），以提高首次审核通过率。这是规避审核被拒的参考做法，**不是长期合规方案**。
:::

具体建议：

1. **审核描述**：将小程序描述写为个人类型内容，如「这里是我的个人日记小程序，用于记录个人的工作和生活。」
2. **审核截图**：不要截取社交功能（如评论区、用户互动）相关页面，截图聚焦文章详情、个人主页等与所选类目一致的内容。
3. **临时下架分享性内容**：提交审核前，将带推广/分享性质的文章设为不可见，保留个人日志类内容；审核通过后再恢复。

::: danger 请注意
以上做法仅用于提高**首次提交审核**的通过率。审核通过后若持续发布资讯类内容，仍存在被平台下架或封禁的风险（详见 [部署须知 - 重要提醒](intro.md)）。从根本上解决，请使用**企业或个体工商户主体**并开通对应类目。
:::

## 8. 发布上线

等待审核通过后，在 `管理 - 版本管理 - 审核版本` 中点击 `发布` 上线即可。
