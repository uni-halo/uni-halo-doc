# 恋爱日记前台模板

插件内置一套**前台（SSR）恋爱日记模板**。任何 Halo 主题只要安装并启用本插件，无需写任何代码，即可在站点前台展示恋爱日记页面；有定制能力的主题也可以整页接管或只覆盖页头页脚。

- 适用插件版本：**uni-halo v3.0.0+**，Halo：**2.26.0+**
- 管理端内容维护见 [控制台功能](./console)；移动端 App 内管理见项目介绍。

## 一、包含哪些模板

| 模板文件 | 页面 | 说明 |
|---|---|---|
| `templates/love.html` | 恋爱日记首页 | 模块入口与内容总览 |
| `templates/love-stories.html` | 我们的故事 | 故事列表；列表分页采用 `/page/{page}` 段式 |
| `templates/love-albums.html` | 恋爱相册 | 相册列表；**相册详情沿用页内查看器，不单独注册路由** |
| `templates/love-daily.html` | 恋爱日记 | 日记流展示 |
| `templates/standalone/love.html` | 独立渲染版 | 不依赖主题布局的整页版本 |
| `templates/fragments/love-*.html` | 公共片段 | 页面片段、图标 sprite、**锁定/解锁表单**、浮层等 |

## 二、开启与路由

恋爱日记前台能力位于 **插件设置 → 恋爱日记主题**：

| 配置项 | 说明 |
|---|---|
| 启用开关 | **默认关闭**；关闭时插件不注册任何前台路由、不注入任何资源（fail-closed） |
| 首页路径 | 默认 `/love` |
| 故事 / 相册 / 日记路径 | 默认分别解析为 `/love/stories` 等子段。规则：**不以 `/` 开头 = 相对首页路径的子段；以 `/` 开头 = 绝对路径；留空 = 不注册该页面** |
| 主色 / 概览展示等 | 按需调整展示偏好 |

> 背景图取自「通用配置 → 页面设置 → 恋爱日记页」。

## 三、主题如何接管

模板名、`_templateId`、模型字段都属于**主题集成契约**，插件在兼容版本内保持稳定，主题可以放心依赖：

1. **整页接管**：主题在自己的 `templates/` 下放置**同名模板**（如 `love.html`）即可整页接管渲染，无需其他配置。
2. **只覆盖页头页脚**：默认模板通过 `layout :: html(head, content)` 布局契约渲染，页头/页脚由主题提供。主题只需实现该布局，不必复制整页模板。
3. **公共片段**：模板通过 `plugin:uni-halo:fragments/love-page` 等片段引用组织内容，锁定表单、图标 sprite 均由插件片段提供，主题无需自行实现。

> Thymeleaf 表达式请写 `${a ? 'x' : 'y'}`，避免 `${a} ? 'x' : 'y'` 的写法错误。

## 四、相册密码锁定

恋爱相册支持**查看密码**，锁定行为由插件在服务端保证：

- 锁定相册不返回业务字段（图片等数据不出服务端），页面渲染的是**页内解锁表单**，而非遮罩；
- 解锁成功后获得短期访问令牌（HMAC 签名，约 30 分钟），解锁走服务端重取，不经过 cookie/URL；
- 令牌按模块与相册独立生效；
- 锁定数据读取失败时按**已锁定**处理（fail-closed），宁可错锁不可误放。

相关开关位于插件设置的安全控制区域（相册解锁、模块解锁）。

## 五、注意事项

- 恋爱日记内容（相册、日记、故事、清单）在 **Console 恋爱管理**中维护，管理员也可直接在移动端 App 内管理；
- 深色模式适配请同时覆盖 4 种深色标记：`html[data-theme="dark"]`、`html[data-color-scheme="dark"]`、`html.color-scheme-dark`、`html.dark`；
- 模板与路由行为升级会在本文档同步说明，主题侧请避免依赖未在契约中列出的内部实现。
