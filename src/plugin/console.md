# 控制台功能

安装并启用 `UniHalo 配置` 插件后，在 Halo 后台左侧菜单进入插件控制台，可以进行应用内容的管理。主要功能模块如下：

## 功能模块总览

| 模块 | 说明 |
|------|------|
| 欢迎页 | 插件概览与快捷入口 |
| 应用管理 | 应用信息、应用版本维护 |
| 横幅管理 | 小程序轮播图配置 |
| 友链管理 | 友链分组、友链信息、投稿审核 |
| 公告管理 | 公告类型、公告内容维护 |
| 恋爱管理 | 恋爱相册、恋爱清单、我们的故事 |
| 审核配置 | 投稿内容的候选与审核策略 |

## 应用管理

维护小程序「我的」页面等位置展示的应用信息，以及应用版本记录。

- **应用信息**：应用名称、简介、图标等展示信息
- **应用版本**：记录每次发布的版本号与更新说明，小程序端可用于检查更新

## 横幅管理

配置小程序端轮播图：

- 支持从已有内容中选择横幅候选（关联文章、瞬间、相册等）
- 支持自定义横幅图片、跳转链接、排序与展示状态

## 友链管理

小程序端友情链接功能的数据来源：

- **友链分组**：将友链按分组归类展示
- **友链信息**：维护友链站点名称、头像、地址、描述等
- **投稿管理**：用户在小程序端提交的友链申请会进入投稿列表，支持查看详情、通过/拒绝；开启邮件通知后审核结果会发送到申请人邮箱（需在插件设置中配置）

## 公告管理

- **公告类型**：定义公告的分类（如更新公告、活动公告）
- **公告内容**：维护具体公告的标题、内容、生效时间等，小程序端以弹窗/列表形式展示

## 恋爱管理

恋爱日记特色功能的数据维护：

- **恋爱相册**：情侣相册管理，支持照片管理与相册加密（加密相册解锁支持验证码防护，见 [插件配置 - 安全控制](/deploy/config#_2-2-安全控制-safetyconfig)）
- **恋爱清单**：恋爱记录清单（想一起完成的事）
- **我们的故事**：恋爱故事图文记录

## 审核配置

配置友链投稿等内容的候选来源与审核策略，控制哪些内容可以进入审核流程。

::: tip
以上各模块的具体字段说明，可在 Halo 后台插件控制台中查看对应表单的提示信息。插件配置（验证码、邮件通知、悬浮窗等全局参数）在插件「设置」页，见 [插件配置](/deploy/config)。
:::
