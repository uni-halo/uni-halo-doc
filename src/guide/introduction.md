# 项目介绍

[uni-halo](https://github.com/uni-halo/uni-halo) 是一个基于 Halo 2.x 提供的 API 接口开发的开源移动端博客应用，一套源码可编译为微信小程序（推荐）、APP、H5 等多端应用。

- 完全免费开源，包括程序源码、插件源码
- 页面内容支持配套插件动态配置，无需修改代码
- 使用最新流行的技术栈（uni-app + Vue3 + TypeScript + UnoCSS + wot-ui）
- 支持特色功能：恋爱日记
- 支持编译为：小程序（推荐）、APP、H5

## 项目组成

uni-halo 由以下项目组成：

| 项目 | 说明 | 仓库 |
|------|------|------|
| uni-halo | 移动端应用源码（本应用主体） | https://github.com/uni-halo/uni-halo |
| uni-halo-plugin | Halo 配置插件（应用后台配置管理） | https://github.com/uni-halo/uni-halo-plugin |
| uni-halo-static | 静态资源仓库（图片、截图等） | https://github.com/uni-halo/uni-halo-static |
| uni-halo-website | 项目官网 | https://github.com/uni-halo/uni-halo-website |

## 功能清单

|功能名称|状态|功能描述|
|--|--|--|
|首页|完成|展示轮播图、精选分类、最新文章|
|分类|完成|展示文章分类，可以点击分类查看相关的文章|
|图库|完成|展示图片，支持普通和瀑布流查看|
|瞬间|完成|支持瞬间插件的数据展示|
|我的|完成|博主个人的相关信息展示|
|文章归档|完成|展示已发布的文章，按日期归档查看|
|恋爱日记|完成|特色功能：恋爱相册、恋爱清单、我们的故事|
|友情链接|完成|展示站点好友的友链，支持申请友链|
|文章搜索|完成|用于快速搜索文章|
|公告通知|完成|公告类型与公告内容展示|
|数据统计|完成|站点数据可视化展示|
