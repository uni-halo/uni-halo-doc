# 更新说明

::: tip 版本更新说明

- main/master 分支会不定时发布最新的版本代码
- 不定期修复 bug/新增功能，同步发行版本（rc/beta/release）

:::

::: warning 分支版本说明

- main/master 分支为具有稳定性的代码，可随时发行版本
- develop 分支为最新的版本代码，包括未测试的代码以及刚发现的 BUG 修复代码

:::

## 版本记录

### v3.x（当前主线版本）

- 全新架构：基于 `unibest` 脚手架重构，uni-app + Vue3 + TypeScript + Vite + UnoCSS + wot-ui
- 全新请求层：基于 alova 请求策略库的接口封装
- 全新配套插件（uni-halo）：横幅、公告、友链投稿审核（支持邮件通知）、恋爱日记（相册/清单/故事）、应用信息与版本管理、验证码安全控制、主题悬浮窗等
- 多端支持：微信小程序（推荐）、APP、H5
- 全新官网与文档：官网 https://uni-halo.ialley.cn ，文档（本站）全面重写
