# 更新日志

日期：2026 年 09 月 17 日<br/>
版本：v3.0.0<br/>
描述：App 端新增登录体系与移动端管理能力，配套插件 v3.0.0+。

## 更新内容

- 新增：账号密码登录、注册、微信一键登录与微信绑定，登录后返回站点个人访问令牌（PAT），可直接访问 Halo 原生 API 与插件接口。
- 新增：移动端内容管理，管理员可在移动端直接管理恋爱相册、恋爱日记、恋爱故事与瞬间。
- 新增：基于角色的权限控制（RBAC），菜单与按钮按登录返回的 `permissions` 显隐。
- 新增：站点维护模式页，维护期间统一展示维护提示。
- 新增：插件侧登录安全控制，内置登录限流（按用户名 / IP），令牌自动过期与清理。
- 优化：注册页面总数达到 41 个，页面清单与分组在官网完整展示。
